# 内置 Excel / BPS 协议

本站在 OpenAI OAuth 网关内提供 Excel/Basispoints 协议适配，复用原有账号调度、分组、代理、模型映射、用量和计费链路。协议核心移植自 `ranxi2001/sub2api` 的固定提交 `a519cfeb66c253dd39d7728d20d55b7cf9f79897`，来源说明保留在 `backend/internal/service/basispoints/NOTICE.md`。

本功能不依赖独立 Excel Bridge 容器或 `.s2plugin`。历史方案见 [EXCEL_BRIDGE_CN.md](EXCEL_BRIDGE_CN.md)，两者不共享会话和配置。本实现包含协议、账号选项、默认模板、图片及独立 OAuth 授权，包含独立 Excel 自动登录工作器；不引入参考项目的代理池、自动移组、Codex 自动重登或 TOTP 更换。

## 管理入口

- **系统设置 → 功能开关 → Excel / BPS 协议与图片支持**：控制全局开关、图片传输、容量和图片限额策略。该区域使用自己的保存按钮。
- **账号管理 → 新建或编辑 OpenAI OAuth 根账号 → Excel / BPS 协议**：开启账号协议，选择模型及附加选项。
- **智能运维 → Excel / BPS 默认设置**：保存账号选项模板。在账号表单点击“应用智能运维默认设置”后复制到当前表单，再保存账号才生效。修改模板不会批量改写已有账号，也不会自动启用新账号。

全局协议默认开启，账号默认关闭。初始模型范围为 `gpt-6-astra`、`gpt-5.6-sol`、`gpt-5.6-terra`；可修改或选择所有模型。全局关闭会隐藏账号选项、停止 BPS 转发及临时图片下载，保留账号已保存的选项。数据库读取失败时，已选择 BPS 的请求明确返回错误。

## 账号与授权

仅支持非免费套餐的普通 OpenAI OAuth 根账号；影子账号、Agent Identity、PAT 和 API Key 不适用。是否实际拥有 BPS 和某个模型的权限由上游决定。

已有 Codex OAuth 账号：

1. 在编辑账号中开启 Excel / BPS，进入“Excel 独立授权”。
2. 生成并打开官方授权链接，登录同一用户并选择同一工作区。
3. 将包含 `code` 和 `state` 的完整官方回调地址粘贴回表单，保存 Excel 授权。
4. 保存账号的协议开关与模型范围。

### 自动授权

已有 Codex OAuth 账号也可在编辑页的 **Excel / BPS → 自动 Excel 授权** 中配置：

1. 开启自动授权，填写该账号的登录邮箱、密码；启用 2FA 的账号同时填写长期 Base32 TOTP 密钥（不是六位验证码）。
2. 点击“保存自动授权设置”。密码和 TOTP 留空表示保留原值；更换邮箱须重新输入密码。此保存独立于外层账号表单。
3. 保存外层账号 BPS 开关及模型范围。账号须处于启用且允许调度状态，全局 BPS 开关须开启。
4. 后台每分钟检查一次队列，使用当前绑定的账号代理登录官方 Excel OAuth，并校验同一用户、工作区和客户端。页面自动刷新任务状态；授权等待期间普通 Codex 请求继续走原协议，取得授权后匹配模型才进入 BPS。

自动授权仍需要真实登录资料，不能把已有 Codex refresh token 转成 Excel token。官方额外安全验证会停止本次尝试，页面提示改用手动授权；不自动轮换代理。失败至少间隔 30 分钟重试，单实例串行登录，数据库租约防止多个实例重复执行。成功后的 Excel 令牌沿用原有独立刷新；刷新明确返回 invalid_grant 时，已启用的自动授权会重新排队。

关闭并保存自动授权会清除已保存的登录资料、使旧任务失效，保留已取得的 Excel 授权。删除账号时保留账号软删除历史行，并在同一事务内清除独立 Excel 授权与自动登录密文；并发保存和自动任务不得在删除后重建密文。配置修改、账号身份改变或手动授权更新时，旧自动任务不得覆盖新状态。系统不把密码、TOTP、代理凭据、令牌或外部登录异常正文写入日志；自动授权设置接口的审计请求体整体省略。

登录资料单独加密保存在 `account_excel_auto_authorizations`，不进入普通账号导出。页面只回传邮箱和是否已配置密码/TOTP。迁移 `248_excel_auto_authorizations.sql` 仅新增该表和索引，不改写现有账号。回滚应用时可保留新增表，恢复时须保留现有运行时加密密钥。

`deploy/Dockerfile` 构建并携带 `/opt/excel-oauth-runtime`，固定参考项目与 toSub2 版本，包含 Python、Node 和所需库，应用运行时不下载代码。依赖来源与许可见 `tools/excel-oauth-runtime/NOTICE.md`。后端内置 Worker 随服务启停；缺少运行时会显示“尚未就绪”且不领取任务。本地直接运行 Go 服务不自带该目录，可使用手动授权；完整自动流程由标准发布镜像提供。

独立授权使用 Excel 官方客户端 `app_fnr0pYvVwwFDocDumLG3H2Bp`、PKCE 和固定官方 HTTPS 回调。服务端交换授权码并核对用户、工作区及客户端，浏览器不会收到独立授权令牌。普通 Codex RT 不能通过改写客户端 ID 转成 Excel RT。

也可在新建账号时选择 **Excel OAuth（仅用于 BPS）**，按现有 OAuth 授权流程创建专用账号。专用账号只能进入已启用且模型匹配的 BPS 路由；选号时排除已关闭、模型不匹配及原生图片、Live、compact 请求。直接请求不支持的原生路由时返回明确错误，不向 Codex 发送 Excel 凭据。专用账号的 Responses token 预估在本地完成，不支持 Codex 额度查询、模型清单同步及原生测试；验证专用账号请使用 BPS 业务请求。

独立 Excel 令牌与主账号令牌分别保存、刷新。主令牌并发轮换时，复核身份后重试保存已取得的 Excel 令牌，不重复向上游刷新。刷新使用账号当前绑定的代理，采用本地锁、Redis 刷新锁和数据库比较更新，防止并发覆盖轮换令牌。授权无效、身份不匹配或刷新失败时需重新授权。授权保存立即生效，与外层账号表单的保存相互独立。

### 鹈鹕与糖果账号测试

OpenAI OAuth 账号开启 Excel/BPS 后，鹈鹕与糖果测试（包括单账号及后台批量账号测试）使用独立 Excel 授权及账号代理，通过 BPS 执行对应题目，并保留推理强度和流式输出；鹈鹕沿用现有测试费用统计。Excel 专用账号也支持这些测试。模型先按账号映射一次，再检查 Excel 模型范围；未开启 Excel 的普通账号继续使用原生 Codex。

已开启 Excel 的鹈鹕与糖果测试不会回退原生协议：未授权或自动授权仍在等待、全局关闭、模型不在范围内、上游拒绝、限流及流中断都会显示对应错误。错误沿用 BPS 的脱敏信息，不暴露令牌或上游原始敏感正文。测试不会因 403 自动关闭账号 Excel 开关，后续测试仍验证 Excel；业务请求的“普通 403 自动关闭”选项保持原有行为。普通连通性及原生图片测试不属于此入口。

糖果测试仍先检查账号可用性，拒答、截断、未完整结束或无法可靠解析的答案不参与正常/下降判分，也不执行自动调组。单账号选择与定时范围见 [账号测智说明](ACCOUNT_INTELLIGENCE_TESTS_CN.md)。

## 协议与账号选项

支持 Responses、Chat Completions、Anthropic Messages 的流式与非流式入口；Responses WebSocket 通过本站现有 HTTP bridge 转为 BPS SSE，并逐事件返回 WebSocket JSON 帧。支持工具转换、工具结果、完整历史、结构化输出、图片及用量转换。

模型范围按渠道或调度映射、账号模型映射后的最终名字匹配，HTTP 与 WebSocket 保持一致。普通 Codex 账号的其他模型继续走原协议；请求包含不支持的托管工具且未启用省略选项时，也使用原协议。Excel 专用账号无法使用这类原生回退。BPS 不支持仅凭 `previous_response_id` 恢复 HTTP 历史，HTTP 客户端须发送完整历史；WebSocket 使用本站已有历史重放链路。

账号选项：

| 选项 | 行为 |
| --- | --- |
| 所有模型 / 指定模型 | 决定哪些映射后的模型走 BPS |
| 省略不支持的托管工具 | 允许移除 BPS 无法执行的托管工具；会减少可用能力 |
| 忽略加密历史 | 去掉无法跨协议转发的加密内容；该部分上下文会丢失 |
| 普通 403 自动关闭 | 按本次实际使用的授权版本关闭当前账号的 BPS 开关，后续新授权不受旧请求影响，保留原账号；模型权限变化的 403 不触发全账号关闭 |
| 缓存创建按普通输入计费 | 将缓存创建部分按普通输入处理，避免额外收取缓存创建费用 |

BPS 直接使用账号代理访问 `bps.openai.com`，不注入 Codex 门票、Cookie 或 OAuth 插件头，禁止上游重定向。原生请求策略、鉴权、分组限制及计费仍由本站执行。BPS 的 429 和模型权限冷却与 Codex 健康状态隔离；冷却期间明确返回错误，不保证调度器自动选择另一个 BPS 账号。

已被接受的生成请求断流或带内失败时不会重放。明确的加密推理拒绝或受限工具格式纠正按协议适配器的条件处理，纠正产生的用量合并记录。下游只收到归一化错误，不返回原始上游敏感正文。

## 图片支持

默认使用 **BPS 原生附件上传**：通过账号的 Excel 凭据及代理上传图片，得到文件引用后再发送生成请求。原生上传仍限制单图 20 MiB、单次图片合计 32 MiB；上传失败不发送后续生成请求。

可改为 **临时 HTTPS 图片中转**：设置本站可公开访问的 HTTPS 域名，BPS 通过不可猜测且有时效的 `/api/bps-images/:id` 读取图片。文件放在 `$DATA_DIR/bps-images`（未设置时为 `./data/bps-images`），受数量、容量和有效期约束，不使用永久公开文件名。多实例部署需保证能力 URL 回到保存图片的实例。未知或过期能力 URL 在内存索引中直接拒绝，不读取数据库、不创建图片中转实例。关闭图片功能或全局协议后，临时下载返回 404。

图片支持开关控制本站对内嵌图片的转换与上传；已有上游文件引用和 HTTPS 图片的可用性仍受协议及上游限制。

图片限额策略：

- **保持现状**：执行配置的硬上限。
- **提醒并拦截**：接近上限时提醒压缩；首次提醒后，同一会话重试可继续，达到预留边界时必须压缩。
- **自动压缩历史图片**：要求可识别的 Codex 客户端、稳定会话标识和 Redis 状态；压缩旧图片历史后继续生成，额外模型用量计入当前请求。客户端需回传压缩结果；不满足条件时明确报错，不静默删除历史。

请求体大小、同时处理数量和转换内存预算均可配置；总预算至少为请求体上限的 8 倍。Nginx/Caddy 和本站原有请求体上限仍然生效。图片策略的 Redis 摘要、警告和检查点有效期为 2 小时，不保存原始图片或提示词。

## 存储与接口

全局配置存于现有 `settings.excel_bps_config` JSON；账号选项存于 `accounts.extra.openai_excel_bps*`。新增迁移 `247_excel_oauth_grants.sql` 创建 `account_excel_oauth_grants`，保存每账号独立授权密文；账号软删除由仓储事务清除该表及 `account_excel_auto_authorizations` 中的密文，硬删除仍由外键级联删除。密文使用本站现有 AES-GCM 加密器及运行时加密密钥；迁移或恢复时必须保留原密钥。普通账号导出不包含独立 Excel 授权；搬迁应保存该表及原加密密钥，不能只导出账号 JSON。

管理员接口复用现有管理端鉴权：

- `GET/PUT /api/v1/admin/intelligent-ops/excel-bps`：读取或更新全局开关、默认模板、图片配置；PUT 只修改提供的顶层部分。
- `GET/PUT /api/v1/admin/openai/accounts/:id/excel-auto-authorization`：读取脱敏自动授权状态或保存/清除登录资料。
- `GET /api/v1/admin/openai/accounts/:id/excel-authorization`：读取脱敏授权状态。
- `POST /api/v1/admin/openai/accounts/:id/excel-authorization/url`：生成官方 Excel 授权链接。
- `POST /api/v1/admin/openai/accounts/:id/excel-authorization`：交换授权码并保存独立授权。
- `GET /api/bps-images/:id`：有时效的图片能力 URL，无管理员会话要求。

该迁移只增加独立表，不改写既有账号凭据。回退旧应用可保留该表和配置；不要删除授权表或加密密钥。正式发布继续使用仓库既有 staging → 同 commit/run 的 prod 流程。

## 验证边界

本地测试覆盖协议核心、各 HTTP 入口、本地真实 WebSocket 连接的多轮历史重放、工具目录继承及原生凭据切换、账号代理隔离、图片上传及失败、流式失败不重放、用量转换、模板应用、授权身份检查、CAS 冲突和并发刷新。新增表的迁移、令牌轮换与删除级联通过隔离 PostgreSQL 验证。

合成令牌和模拟上游不能证明真实 BPS 权限或生产可用性。正式开放前需用获授权的真实账号在 staging 验证：授权及刷新、流式响应、工具往返、图片、WebSocket 多轮、压缩和余额扣费，并确认生产代理能访问 BPS。本地实现不代表已部署。
