# 内置 Excel / BPS 协议

内置 Excel/BPS 适配器让现有 OpenAI OAuth 账号通过 BPS 上游处理 Responses 请求。管理员可在“系统设置 → 功能开关”开启协议与图片支持，在账号创建、编辑、批量编辑中配置路由，并在“智能运维 → 自动配置”维护可复用的默认模板。

协议总开关和图片支持默认关闭。配置使用现有 `settings` 与 `accounts.extra`，不新增数据库迁移；开启全局协议不会自动开启所有账号。本文说明源码能力，不代表已完成正式环境发布或真实 OAuth 验收。

## 开启与日常操作

1. 在功能开关中的“协议功能”开启 Excel/BPS，点击卡片自己的“保存 Excel/BPS 配置”。该保存入口独立于系统设置页面的其他配置。
2. 打开一个普通 OpenAI OAuth 账号，选择“开启并套用默认配置”或“开启初始配置”，检查模型范围后保存账号。免费套餐、影子账号、Agent 身份、PAT 与 API Key 账号不能启用。
3. 通过 HTTP `/v1/responses` 发送请求。模型名称先经过账号映射，再与 BPS 模型范围匹配。范围外模型沿用原有协议；“全部模型”只是路由选择，不赋予上游模型权限。
4. 账号测试按钮对命中 BPS 范围的模型使用实际 BPS 转发链。压缩需要通过 HTTP `/v1/responses/compact` 验证。

修改默认模板只影响下一次点击“套用默认配置”填入的表单，不批量更新已有账号，也不自动保存当前账号。批量修改须先勾选“批量修改 Excel / BPS 配置”；未勾选时保留原配置。

关闭总开关后，新请求停止走 BPS，账号选项隐藏，新的自动恢复探测停止。已发出的请求不强制中断。普通 Codex OAuth 账号回到原协议；使用官方 Excel client ID 的专用凭据无法回退 Codex，会返回明确的路由不可用错误。重新开启总开关会恢复仍已启用的账号配置。

## 账号选项

| 选项 | 行为 |
| --- | --- |
| 模型范围 | 按账号映射后的模型名匹配；全部模型通过移除范围字段表示，空列表不表示全部模型 |
| 忽略不支持的加密内容 | 将无法转发的加密历史替换为省略提示，保留可处理的明文；不恢复密文内容 |
| 403 时自动关闭协议 | 实际 BPS 生成返回 403 时关闭该账号的 BPS 开关，保留账号与原生协议能力 |
| 定时探测恢复 | 仅探测有服务端自动关闭标记的账号；每次用随机挑战回答验证完成事件，成功后重新启用 BPS |
| 恢复间隔 | 1–10080 分钟，默认 60；后台每分钟检查，跨实例以数据库原子认领避免重复探测 |
| 403 自动调整分组 | 替换账号全部现有分组；显式选“退出所有分组”才移除全部绑定。恢复协议不会还原分组 |
| 缓存写入按输入计费 | BPS 缓存写入归入普通输入桶，保留缓存读取和上游原始使用量，避免重复扣费 |
| 保持 BPS，省略不支持的托管工具 | 显式省略不支持的托管搜索/图片生成声明并提示模型；强制工具选择仍拒绝 |

默认工具策略对需要原生托管能力的请求回退 Codex；Excel 专用凭据不能这样回退。函数、自定义工具和命名空间工具由协议适配器转换。使用加密历史省略或切换协议后，建议新建会话，避免依赖旧协议生成的状态。

BPS 的 429 只冷却该账号的 BPS 模型路由，不写入 Codex 共享配额、不降低共享账号健康评分。尚未输出时可切换账号；已输出、工具修复或附件接受后的失败按阶段处理，禁止不受控重放。客户端取消与上游故障分别处理。

## 图片支持

支持两种方式，配置保存后新请求立即读取：

- **原生附件上传**：使用选中账号的 OAuth 凭据和代理上传到 BPS 附件端点，无需公开图片域名。单图 20 MiB、合计 32 MiB 的原生上传限制独立于中转容量设置；工具截图按 BPS 协议转换。
- **临时 HTTPS 中转**：将图片保存在当前实例的 `DATA_DIR/bps-images`（未设置 `DATA_DIR` 时为 `./data/bps-images`），通过不可猜测且有有效期的 URL 提供给上游。填写上游能够访问的 HTTPS origin，例如 `https://api.example.com`，不附加路径。入口为 `GET/HEAD /api/bps-images/:token`。

临时图片链接的持有者可在有效期内读取图片。关闭图片支持、切换到原生模式或关闭总开关后停止提供中转链接。中转文件属于本实例，多个副本部署时必须保证图片链接回到持有文件的实例；Redis 只保存会话进度摘要，不保存图片或对话。

请求体、在途请求数、估算处理预算、单图/合计大小、文件数量、磁盘配额和有效期均可配置。处理预算必须至少为请求体上限的 8 倍，增加并发上限不会自动扩大预算。最终入口上限仍受 `gateway.max_body_size` 和反向代理请求体限制约束。开启图片支持时，共享准入控制覆盖 OpenAI/复合分组的 Responses、Chat Completions、Messages HTTP 入口，先预留预算再读取请求体；资源不足返回 503，超出请求体限制返回 413。

图片限额策略可选关闭、提前提醒手动 compact、自动 compact 历史图片。后两种需要稳定的会话身份与可用会话状态；自动 compact 额外消耗上游额度，新提交的图片本身超限仍需分批发送。提高中转容量不会绕过原生附件上游限制。

## 接口与持久化

所有管理接口沿用管理端认证：

| 方法与路径 | 用途 |
| --- | --- |
| `GET/PUT /api/v1/admin/settings/excel-bps` | 读取/整体保存协议及图片配置 |
| `GET/PUT /api/v1/admin/auto-config` | 读取/保存 `{ "excel_bps": ... }` 默认模板 |
| 现有账号创建、更新、批量更新接口 | 保存 `extra` 中的 BPS 配置 |

总开关为 `excel_bps_enabled`，模板为 `excel_bps_defaults`，图片设置统一使用 `excel_bps_image_*`。账号开关为 `openai_excel_bps`，范围为 `openai_excel_bps_models`，其他选项使用同名前缀。

403 关闭时间、恢复探测时间和自动转组结果由服务端维护。普通账号编辑不能伪造这些标记；重新启用协议会清除自动关闭和探测记录。自动动作在数据库内检查凭据与配置快照，避免覆盖并发人工修改，并通知现有调度缓存。

## 兼容边界

- 本次接入 HTTP/SSE Responses 与 compact，不把 WebSocket、Chat Completions 或 Anthropic Messages 自动转换为 BPS。普通 Codex 凭据的其他入口保持原行为；Excel 专用凭据不允许用于原生 Codex。
- 请求、原生附件与恢复探测沿用账号已有代理。未迁入来源仓库的 Mihomo 会话代理池、自动质量运维、双 OAuth 凭据管理与专用 Excel 登录界面。导入的 `openai_excel_bps_mihomo=true` 配置会拒绝使用，不静默改为直连。
- 现有 Excel OAuth 凭据若带官方 Excel client ID，刷新和交换使用对应 `unified=true` 参数，不混用 Codex 的 scope 与客户端头。真实权限仍需持有者用授权账号验证。
- 原生 Codex 的 compact 探测结果、票据门禁与 BPS 按所选模型分流；原生协议继续沿用现有门禁。
- 若部署启用自定义上游域名白名单，需允许 `bps.openai.com`。仓库默认白名单已加入该域名。
- 此功能与 [Excel Bridge 独立上游](EXCEL_BRIDGE_CN.md) 相互独立；内置 BPS 在网关内直接转发，不经过外部 Bridge 容器或 OAuth 插件。

## 来源与验证

移植来源为 `ranxi2001/sub2api` 的固定提交 `e8fe22e8b637ea7b26f11b081b39aa518d0a90ec`，不是整仓合并。协议包保留 `backend/internal/service/basispoints/NOTICE.md` 中的上游来源说明；本项目适配了账号代理、调度、管理接口、计费和前端。

本地验证覆盖协议转换、流式结束、工具回放、结构化输出、图片上传与准入、403 关闭/转组/恢复、缓存写入计费、设置持久化、账号表单与原有网关回归。测试使用合成凭据和模拟上游，没有读取个人登录态，没有以生产账号发起真实推理。

真实验收需在隔离 staging 开启单个已授权账号，分别检查文本/流式/工具/图片/compact 的完整响应与实际用量，并核对使用记录、余额、代理和错误处理。正式上线继续遵循仓库的同一 commit、staging run 与用户确认门禁。

本地竞态专项覆盖 BPS 服务、完整协议包与图片准入，均通过。扩大到原有 Anthropic/WS 回放测试时，既有 `openai_compat_model_test.go` 的多个并行测试同时修改 Gin 全局模式，触发测试环境竞态；该文件不在本次改动范围，普通完整回归通过。不能将 BPS 专项通过表述为全仓竞态通过。
